# Ψηφιακό μενού — Μεζεδοπωλείο Τρύφων

Στατικό site (χωρίς build) + Supabase. Τρεις σελίδες, μία πηγή δεδομένων.

| Αρχείο | Τι κάνει |
|---|---|
| `tv.html` | Η οθόνη του μαγαζιού. Κάθετη ή οριζόντια, αυτόματη εναλλαγή σελίδων, ζωντανή ενημέρωση. |
| `index.html` | Ο κατάλογος για τον πελάτη — αυτό βάζεις πίσω από το QR στα τραπέζια. |
| `admin.html` | Η διαχείριση από κινητό. Δύο ρόλοι (ιδιοκτήτης / προσωπικό). |
| `app.js` | Κοινές συναρτήσεις (φόρτωση, realtime, offline cache). |
| `config.js` | URL + anon key του Supabase. Το μόνο που αλλάζει αν μεταφερθεί αλλού. |

## Deploy

Δεν χρειάζεται build. Ό,τι φιλοξενεί στατικά αρχεία κάνει:

```bash
npx vercel --prod        # μέσα από τον φάκελο
```

ή drag-and-drop τον φάκελο στο vercel.com/new.

### Πώς επιβάλλονται οι ρόλοι

Δεν είναι κρυμμένα κουμπιά — είναι RLS στη βάση:

- **Δημόσια ανάγνωση** σε `categories`, `menu_items`, `settings` (η οθόνη και το QR menu δεν κάνουν login).
- **Ιδιοκτήτης**: πλήρη δικαιώματα σε όλους τους πίνακες.
- **Προσωπικό**: μόνο `UPDATE` σε `menu_items`, και ένας trigger (`enforce_staff_scope`) απορρίπτει
  την αλλαγή αν πειραχτεί οτιδήποτε πέρα από `is_available` και `is_special`.

Δηλαδή ακόμα κι αν κάποιος ανοίξει το console και στείλει request με τιμή, η βάση το κόβει.

## Θέματα και γραμματοσειρές

Αλλάζουν από Ρυθμίσεις, με ζωντανή προεπισκόπηση της πραγματικής οθόνης.

- **Θέματα** (`settings.theme`): Ταβέρνα, Ανθρακί, Αιγαίο, Λαδί, Κρασί, Χαρτί (φωτεινό).
  Ορίζονται στο `THEMES` στο `app.js` — κάθε ένα δίνει φόντο, κείμενο, τόνο και γραμμές.
- **Γραμματοσειρές** (`settings.font`): Κλασικό, Παραδοσιακό, Μοντέρνο, Δυνατό.
  Ορίζονται στο `FONTS`, φορτώνονται δυναμικά από Google Fonts με ελληνικό subset.

Το θέμα ισχύει στην οθόνη· ο κατάλογος του πελάτη κρατάει το φωτεινό «χαρτί» look
(διαβάζεται καλύτερα στον ήλιο) αλλά ακολουθεί την ίδια γραμματοσειρά.

- **Φόντο φωτογραφίας** (`settings.bg_url`, `settings.bg_dim`): ανεβαίνει από τις Ρυθμίσεις.
  Η εικόνα σμικρύνεται στον browser σε 1920px / JPEG q82 πριν φύγει, και αποθηκεύεται
  στον δημόσιο κάδο `branding` του Supabase Storage (max 8 MB, μόνο jpeg/png/webp).
  Πάνω της μπαίνει πέπλο στο χρώμα του θέματος με ρυθμιζόμενη ένταση 20–95% —
  χωρίς αυτό, καμία φωτογραφία δεν αφήνει το μενού ευανάγνωστο.

Για προεπισκόπηση χωρίς αποθήκευση: `tv.html?theme=aigaio&font=slab&bg=<url>&dim=60`.

## Πρακτικά για την εγκατάσταση

- Η οθόνη ανοίγει το `tv.html` σε kiosk browser. Σε Raspberry Pi:
  `chromium-browser --kiosk --noerrdialogs --disable-infobars <URL>/tv.html`
- Αν πέσει το ίντερνετ, η σελίδα κρατάει το τελευταίο μενού από localStorage
  και βάφει το υποσέλιδο πορτοκαλί.
- Οι σελίδες σπάνε αυτόματα ώστε να χωράνε πάντα — δεν κόβεται ποτέ πιάτο στη μέση.
- Ελαφρύ drift ανά 12 λεπτά για προστασία από burn-in.
